## 口径（可复算，两种都过）

**口径①（矩阵主口径）逐行 md5 拼接后再 md5**，行数单独 `count(*)`：

```sql
-- MySQL
SET SESSION group_concat_max_len=1073741824;
SELECT COUNT(*), MD5(GROUP_CONCAT(h ORDER BY id SEPARATOR ''))
FROM (SELECT id, MD5(CONCAT_WS('|', id, payload)) h FROM acc_mm) x;
-- PostgreSQL
SELECT count(*), md5(string_agg(h,'' ORDER BY id))
FROM (SELECT id, md5(concat_ws('|', id, payload)) h FROM acc_mp) x;
```

两端跑的是**同一套算式**，所以数字可以直接对。注意这与 `verify` 内部的跨端指纹不同：
MySQL 侧是客户端 `mysql-canon-v1`、PG 侧是服务端 `pg-hashtextextended-v1`，两个数永远不可能相等
（`docs/VERIFY.md` §1），矩阵不拿它们比。

**口径②（第二口径）整表导出取 md5**：两端各按主键导出 `id<TAB>payload` 文本，对文件取 md5。
2026-11-11 实跑结果（`notes/matrix3/20261111/export_md5.log`）：

```
EXPORT_MD5 combo=mysql-mysql  source=3960340335b4cd0c314d989823288db1 target=3960340335b4cd0c314d989823288db1 rows_src=20000 rows_dst=20000 equal=yes
EXPORT_MD5 combo=mysql-pg     source=3960340335b4cd0c314d989823288db1 target=3960340335b4cd0c314d989823288db1 rows_src=20000 rows_dst=20000 equal=yes
EXPORT_MD5 combo=pg-mysql     source=3960340335b4cd0c314d989823288db1 target=3960340335b4cd0c314d989823288db1 rows_src=20000 rows_dst=20000 equal=yes
```

两个口径的哈希值不同（算式不同），但每个口径内部源=目标。

**第三判据（应用侧全表逐行）**：每格跑完都跑 `jinliang verify --level data`，它不是抽样——
`verify.log` 里 `full_scan_rows:20000 matched:20000 blocks_mismatched:0`，即 20000 行逐行全表比对。
三个判据（口径①/口径②/verify L2）都过才算这一格过。

**耗时口径（两段分开，都按「追平」算，不含引擎收尾空闲）**：

- 快照段：首轮 `run` 启动 → 目标端行数 == 源行数。
- 增量段：源端写下三笔（增/改/删）→ 目标端三笔同时可见。
- 为什么不把 `--stop-when-idle 5s / 3s` 算进去：第一版就是按 `run` 墙钟算的，结果 300 行和
  20000 行都显示 `6.3s`——那不是搬运耗时，是「空闲 5 秒后收尾」的常量。`run` 墙钟改记在
  `result.json` 的 `snapshot_wall` 里（本轮 6.8–7.3s），要算总账用那个。

## 已知偏差 / 不在这张表里的东西

- **MySQL→PG 快照 0.48s 明显快于 MySQL 目标端（2.0–2.1s）**：PG 目标端走 COPY/批量写入，
  MySQL 目标端是逐行 upsert（`INSERT … ON DUPLICATE KEY UPDATE`）。同量级下 4 倍差距是预期的，
  不是某一格漏搬——行数、两个口径的 md5、verify 逐行全表三方都对得上。
- 本矩阵只验**数据面一致性 + 两段耗时**，不含：按表暂停（#102/#90）、kill -9 续跑（#106）、
  退出码 3 口径。kill -9 那条仍可用 `scripts/acceptance_matrix.sh --kill --only mysql-postgres` 单独跑。
- 只在 MySQL 8.0.28 + PG 17.11 上跑过；5.7 / 8.4 / 9.x 四档版本覆盖是另一件事（B 项），
  本文件不冒充版本覆盖结论。
